# 로또 번호 생성기 (PWA)

균등 무작위 생성 + 인기 조합 필터. 예측 기능 없음 — 모든 조합의 확률은 1/8,145,060으로 동일하며,
필터는 당첨 시 분할 인원 기댓값만 낮춘다.

## 기능
- 비인기 조합 생성 (인기 패턴 7종 배제, CSPRNG)
- 회차별 당첨번호 조회 (1회~현재)
- 출현 빈도·핫/콜드 통계 (범위 선택)
- 내 번호 저장 및 당첨 자동 확인 (localStorage)
- PWA — 홈 화면 추가, 오프라인 동작

## 배포
1. GitHub 저장소 생성 후 이 파일들을 push
2. Settings → Pages → Source: `main` 브랜치 `/ (root)` 선택
3. `https://<계정명>.github.io/<저장소명>/` 접속
4. 휴대폰 브라우저에서 "홈 화면에 추가"

## 데이터 갱신
`.github/workflows/update.yml`이 매주 토요일 22:00 KST에 동행복권 API에서
신규 회차를 받아 `data/lotto.json`에 자동 커밋한다. Actions 탭에서 수동 실행도 가능.
